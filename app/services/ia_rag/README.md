# `services/ia_rag/`

Índice y búsqueda de textos publicados de cada cliente. Está preparado para
el chat público, pero aún no hay ruta/widget público ni indexación automática
conectada en el código auditado. No usarlo como fuente de cifras, precios o
existencias; esas respuestas salen de `services/ia_datos/`.

Inventario y estado: [IA_ARCHIVOS_Y_DEPENDENCIAS.md](../../docs/IA_ARCHIVOS_Y_DEPENDENCIAS.md).
